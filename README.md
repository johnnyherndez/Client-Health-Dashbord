# Client-Health-Dashbord

<b>What this answers:</b> which active clients are quietly at risk right now, and which CRM records are already wrong. 
<b>Who uses it:</b> account managers and leadership, in weekly pipeline/retention review. 
<b>Decision it improves:</b> who gets a proactive check-in call this week, and which client records need a status correction before they distort forecasting.
